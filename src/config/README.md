# Config モジュール

アプリケーションの設定管理機能を提供するモジュールです。パス設定、設定ファイルの読み込み、各種定数の管理を行います。

## 📁 ファイル構成

| ファイル | 説明 |
|---------|------|
| `path.py` | ファイルパスとディレクトリの設定管理 |
| `release_constants.py` | リリース分析用の定数定義 |
| `bot_accounts.csv` | ボットの一覧（判定の決まり ④）。各行に出どころの URL を書く |

## 🔧 主要機能

### Path管理 (`path.py`)
- **ディレクトリパス定義**: データ保存先、設定ファイル場所などの統一管理
- **相対パス解決**: プロジェクトルートからの相対パス計算
- **クロスプラットフォーム対応**: Windows/Linux/macOS対応のパス処理

### ボットの判定
判定のコードは `src/utils/bot_detection.py`、設計書は `src/utils/bot_detection.md`。
アカウントは、次の ①〜④ のどれかに当てはまればボットとみなす。

| 順 | 決まり | 根拠 |
|---|---|---|
| ① | Gerrit の `SERVICE_USER` の印がある | Gerrit 公式 |
| ② | メールアドレスが `gserviceaccount.com` で終わる | Google Cloud 公式 |
| ③ | `name` か `display_name` の最後の語が Bot・CI（区切りありは大小区別なし、区切りなしは大文字の Bot・CI のみ） | OpenDev 公式の命名規則 |
| ④ | `bot_accounts.csv` に載っている（ホスト必須。`account_id`・`username`・`email` で照合し、名前では照合しない） | 行ごとに書いた出どころの資料 |

メッセージは、`tag` が `autogenerated:` で始まるもの・投稿者がボットのもの・投稿者がチケットの作成者本人のものを、人間のレビューとして数えない。

一覧（`bot_accounts.csv`）には、①〜③ で拾えず、かつ出どころの資料が見つかったものだけを載せる。
**一覧の正本は `bot_accounts.csv`。下の表はその写しなので、一覧を変えたら表も同時に直す。**

## 📋 設定項目

### パス設定 (`path.py`)
```python
# 主要なディレクトリパス
DEFAULT_DATA_DIR: Path        # データ保存ディレクトリ
DEFAULT_CONFIG: Path          # 設定ファイルディレクトリ
DEFAULT_RESULTS_DIR: Path     # 結果出力ディレクトリ
```

## 🚀 使用方法

### パス設定の利用

```python
from src.config.path import DEFAULT_DATA_DIR, DEFAULT_CONFIG

# データファイルの保存
data_file = DEFAULT_DATA_DIR / "openstack" / "nova.json"

# 設定ファイルの読み込み
config_file = DEFAULT_CONFIG / "bot_accounts.csv"
```

### ボットの判定の利用

```python
from src.utils.bot_detection import BotDetector, host_of

detector = BotDetector(host_of("nova"))   # ホストごとに作る
detector.is_bot(message["author"])        # ①〜④ のどれかに当てはまれば True
detector.reason(message["author"])        # "service_user" / "gserviceaccount" / "name" / "list" / None
```

## 📁 ディレクトリ構造

```
data/                          # DEFAULT_DATA_DIR
├── openstack/                 # OpenStackデータ
│   ├── component_summary.csv
│   ├── releases_summary.csv
│   └── [project]/
│       ├── changes/
│       └── commits/
├── processed/                 # 処理済みデータ
└── results/                   # 分析結果

src/config/                        # DEFAULT_CONFIG
├── path.py                        # パス定義
├── release_constants.py           # リリース分析用の定数
└── bot_accounts.csv               # ボットの一覧（出どころ付き）
```

## ⚙️ 環境変数

以下の環境変数で設定をオーバーライド可能：

```bash
# データディレクトリの変更
export REVIEW_PRIORITY_DATA_DIR="/custom/data/path"

# 設定ディレクトリの変更
export REVIEW_PRIORITY_CONFIG_DIR="/custom/config/path"
```

## 🔧 カスタマイズ

### 新しいパスの追加

```python
# path.py に追加
CUSTOM_OUTPUT_DIR = DEFAULT_DATA_DIR / "custom_output"
```

### ボットの一覧への追加

`bot_accounts.csv` に行を足すときは、①〜③ で拾えないことと出どころの資料があることを確かめ、
`host`・`source`・`url` を必ず書く（`src/utils/bot_detection.md` §2.3・§2.5）。上の表も同時に直す。

## ⚠️ 注意事項

1. **設定ファイルの権限**: 認証情報を含む場合は適切な権限設定
2. **パスの存在確認**: 指定されたパスが存在しない場合の自動作成
3. **設定の検証**: 不正な設定値に対するエラーハンドリング
4. **環境依存**: OS固有のパス区切り文字への対応
