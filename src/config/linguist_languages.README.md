# linguist_languages.yml

GitHub の linguist が使う言語定義（`lib/linguist/languages.yml`）。
E1（ソースコードを含まない）の判定で、拡張子から実装言語のファイルかどうかを決めるのに使う。

- 出典: https://github.com/github-linguist/linguist （MIT ライセンス）
- 取得日: 2026-09-29
- 収録: 836 言語（programming 563 / data 184 / markup 71 / prose 18）

`type: programming` の言語の拡張子・ファイル名だけを「ソースコード」とみなす。
判定の基準を自作せず既存の定義に委ねるのが目的なので、**このファイルは編集しない**。
更新する場合は上記から取り直し、取得日を書き換える。
